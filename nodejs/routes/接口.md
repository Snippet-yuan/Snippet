# Snippet API 接口文档

- 基础路径：`http://localhost:8080/api/v1`
- 统一响应格式：`{ code, message, data }`，`code === 0` 表示成功
- 除登录/注册外，接口需在请求头携带 `Authorization: Bearer <token>`

---

## 一、身份认证

### 1.1 注册

```
POST /api/v1/auth/register
```

**请求体（JSON）**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| email | string | 是 | 邮箱账号（唯一） |
| password | string | 是 | 密码 |
| nickname | string | 是 | 昵称 |

**请求示例**

```json
{
  "email": "user@example.com",
  "password": "123456",
  "nickname": "昵称"
}
```

**成功响应（HTTP 201）**

```json
{
  "code": 0,
  "message": "注册成功",
  "data": {
    "token": "eyJhbGciOi...",
    "user": {
      "id": "1",
      "email": "user@example.com",
      "nickname": "昵称",
      "avatar": "",
      "background": ""
    }
  }
}
```

**失败响应**

| HTTP 状态码 | 场景 |
|---|---|
| 400 | email / password / nickname 为空 |
| 409 | 该邮箱已注册 |

## 二、用户信息

### 2.1 获取当前用户资料

```http
GET /api/v1/users/me
Authorization: Bearer <token>
```

**成功响应（HTTP 200）**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": "1",
    "email": "user@example.com",
    "nickname": "昵称",
    "avatar": "",
    "background": ""
  }
}
```

**失败响应**

| HTTP 状态码 | 场景 |
|---|---|
| 401 | 未携带 token、token 无效或已过期 |
| 404 | 用户不存在 |

### 2.2 搜索用户

```http
GET /api/v1/users/search?keyword=昵称
Authorization: Bearer <token>
```

**查询参数**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| keyword | string | 是 | 昵称模糊搜索；输入纯数字时同时支持用户 ID 精确搜索 |

**成功响应（HTTP 200）**

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    {
      "id": "2",
      "nickname": "好友昵称",
      "avatar": "https://cdn.example.com/avatar.png"
    }
  ]
}
```

**说明**

- 未填写 `keyword` 时返回空数组。
- 最多返回 20 条结果。
- 此接口必须登录。

**失败响应**

| HTTP 状态码 | 场景 |
|---|---|
| 401 | 未携带 token、token 无效或已过期 |

## 三、好友

### 3.1 获取好友列表

```http
GET /api/v1/users/me/friends?page=1&limit=20
Authorization: Bearer <token>
```

**查询参数**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| page | number | 否 | 页码，默认 1，最小值为 1 |
| limit | number | 否 | 每页条数，默认 20，范围 1～50 |

**成功响应（HTTP 200）**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "items": [
      {
        "id": "1",
        "userId": "2",
        "nickname": "好友昵称",
        "avatar": "https://cdn.example.com/avatar.png",
        "onlineStatus": "OFFLINE",
        "lastMessage": "",
        "unreadCount": 0
      }
    ],
    "hasMore": false,
    "page": 1
  }
}
```

**说明**

- 好友关系按双向记录保存。
- 当前后端暂未接入在线状态和消息同步，因此 `onlineStatus` 固定为 `OFFLINE`，新好友的 `lastMessage` 为空、`unreadCount` 为 0。
- 当返回条数等于 `limit` 时，`hasMore` 为 `true`。

### 3.2 添加好友

```http
POST /api/v1/friends
Authorization: Bearer <token>
Content-Type: application/json
```

**请求体（JSON）**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| userId | string 或 number | 是 | 要添加的用户 ID，不能是当前用户自己 |

**请求示例**

```json
{
  "userId": "2"
}
```

**成功响应（HTTP 200）**

```json
{
  "code": 0,
  "message": "添加好友成功",
  "data": {
    "id": "1",
    "userId": "2",
    "nickname": "好友昵称",
    "avatar": "https://cdn.example.com/avatar.png",
    "onlineStatus": "OFFLINE",
    "lastMessage": "",
    "unreadCount": 0
  }
}
```

**失败响应**

| HTTP 状态码 | 场景 |
|---|---|
| 400 | userId 无效，或尝试添加自己 |
| 401 | 未携带 token、token 无效或已过期 |
| 404 | 目标用户不存在 |
| 409 | 已经是好友 |

## 四、帖子

### 2.1 主页帖子流（无限滚动）

```
GET /api/v1/posts?limit=20
GET /api/v1/posts?lastId=35&limit=20
```

**查询参数**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| limit | number | 否 | 每批条数，默认 20，最大 50 |
| lastId | number | 否 | 上一批最后一个帖子的 id；首次请求不传（返回最新），下拉加载时传（返回比它更早的） |

**成功响应（HTTP 200）**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "items": [
      {
        "id": "36",
        "ownerId": "22",
        "ownerNickname": "木子同学14",
        "ownerAvatar": "https://i.pravatar.cc/150?img=39",
        "title": "工作室的一角，慢慢布置起来了",
        "description": "一点点把喜欢的东西填进来，生活要有仪式感。",
        "images": [
          "https://picsum.photos/seed/xxx_0/600/800",
          "https://picsum.photos/seed/xxx_1/600/800"
        ],
        "counters": {
          "likeCount": 100,
          "favoriteCount": 20,
          "commentCount": 8,
          "shareCount": 3
        },
        "liked": false,
        "favorited": false,
        "createdAt": "2026-09-02T10:00:00Z"
      }
    ],
    "hasMore": true
  }
}
```

**说明**
- 首次请求不带 `lastId`，返回最新的一批帖子
- 下拉加载时，把上一批 `items` 里**最后一个帖子的 id** 作为 `lastId` 传入
- 当返回条数 < `limit` 时，`hasMore: false`，表示没有更多了
- 排序：按帖子 id 倒序（最新的在前）
